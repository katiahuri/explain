Before you move on

Can you call this one?

A bot quotes outdated refund terms.

Name three places. Which is the model?

How we would answer

  • Knowledge an old policy document or a stale retrieval index.
  • Context the system instructions still quote the old terms.
  • Memory a cached answer or saved note repeats them.
  • Tools a policy API or database returns old data.
  • Model the terms came from training data before the knowledge cutoff. Only this one is the model.
