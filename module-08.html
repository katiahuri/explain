Before you move on

Can you call this one?

An agent misreads a figure at step 2.

Why did it spread? Name two fixes.

How we would answer

  • Why it spread later steps treat earlier results in state as facts. Nothing re-checked the figure, so every step built on it.
  • Check observations compare the extracted figure against the source before storing it.
  • Add a checkpoint a code check or human review before key numbers are used downstream.
  • Require citations for every figure, and verify them automatically.
  • Make the known steps a fixed workflow, so fewer steps are left to the model.
  • Not enough on its own a bigger model. It lowers the per-step error but doesn’t stop propagation.
