Leave at the door

Five myths this module breaks

MythWhat’s actually true
“A better prompt fixes everything.”Most failures are what’s in the window.
“More context is always safer.”Irrelevant tokens distract and mislead.
“The system prompt is secret and binding.”It can leak, and users can talk around it.
“Ask for JSON and you’ll get it.”Enforce a schema if you can. Validate always.
“One line in the prompt stops injection.”No prompt fixes it. Limit what the system can do.
